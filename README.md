# ReserGO.Utils - Strumenti e Utility per ReserGO

> 📚 Libreria di utilità per il progetto ReserGO in .NET 9 Core

ReserGO.Utils è una libreria contenente tutti gli strumenti e le utility condivise che vengono utilizzate all'interno di ReserGO. Questo progetto fornisce una serie di classi, metodi e strutture, come il supporto per il pattern MVVM, la gestione degli eventi (messaggi), i DTO, e altre utility utili per la gestione del flusso di dati e delle operazioni interne al sistema. Il tutto è scritto in .NET 9 Core.

## ✨ Funzionalità principali

- 📚 **MVVM** - Implementazione del pattern Model-View-ViewModel per una corretta separazione delle preoccupazioni e una gestione efficiente dei dati
- 💬 **Gestione degli eventi (IEvent)** - Strumenti per la gestione dei messaggi/eventi tra componenti
- 🛠 **Utility generiche** - Funzioni e metodi riutilizzabili per operazioni comuni in ReserGO
- 🚀 **Compatibilità con .NET 9 Core** - Sfrutta le ultime funzionalità di .NET 9 Core per performance e scalabilità migliorate
